PXD Web

Install once and .pxd names work in every browser and app on your computer, the same way .com does. Only .pxd lookups go to PXD; everything else on your computer stays exactly as it was. Turn it off any time and nothing is left behind.

Windows 10 / 11Download for Windows
  1. Unzip it.
  2. Double-click Install PXD Web and say Yes.
  3. Use PXD Web ON / OFF / STATUS on your desktop.
LinuxDownload .pxd2 installer
  1. Open it, or run sh PXD-Web-Linux.pxd2.
  2. Enter your password once.
  3. Use PXD Web ON / OFF / STATUS on your desktop.
Try itType a name with a slash at the end the first time: pxd2.pxd/ · bearwallow.pxd/. Without PXD Web every name still opens at pxd2.github.io/name. See every name, or claim one, at PXD2 Names.

Names come from PXD2's registry on GitHub. Each name is minted on a chained public ledger with a deed, and PXD Web refuses a registry that doesn't carry PXD2's signature once the registry is signed.
