# PXD Model Ledger

One append-only, signed, hash-chained log per 3D model (`<model id>.jsonl`). Replay any log with `tools/ledger/pxdledger.py show` to see who holds which license. Licenses are products (print, game, film, lease, edition, buyout), sold by the artist and paid to the artist directly. Nothing here is a coin or a share.
